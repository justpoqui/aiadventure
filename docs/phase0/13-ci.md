# Step 13 — Continuous integration

**Goal:** every push runs the Python tests and the protocol-schema check on
GitHub, so a broken commit is caught immediately.

## 13.1 Workflow file

`.github/workflows/ci.yml`
```yaml
name: ci

on:
  push:
  pull_request:

jobs:
  mind-service:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: mind_service
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - name: Install
        run: pip install -e ".[dev]"
      - name: Tests
        run: pytest -q
      - name: Protocol schemas are up to date
        run: python -m mind.tools.export_schemas --check
```

The LLM smoke test is **not** run in CI, because there is no GPU there. The
`FakeProvider` tests cover the gateway logic.

## 13.2 Godot in CI (optional, later)

Godot can run headless in CI. When you add gdUnit4 tests, the community action
`MikeSchulze/gdUnit4-action` runs them; check its README for the current
inputs. Until then, the Godot side is verified by the manual checks in steps
07–11.

## Check it works

1. Commit and push your branch.
2. On GitHub: **Actions** tab → the `ci` run is green.
3. **Prove it catches mistakes:** change a field in `protocol.py` *without*
   re-exporting the schemas, push, and confirm the run fails on "Protocol
   schemas are up to date". Then export, commit, and push. The run is green
   again.

## Common mistakes

- **The workflow can't find `pyproject.toml`.** Check
  `working-directory: mind_service`.
- **Tests that need Ollama or a GPU.** Anything that needs real hardware is a
  manual tool (`mind.tools.*`), not a test.
